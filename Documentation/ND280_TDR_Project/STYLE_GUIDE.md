# ND280 Graphical Style Guide

## Purpose
All TDR, presentation and engineering architecture diagrams shall use a common visual language.

## Palette
- Hardware: `#4F81BD`
- Firmware / NodeOS: `#2E7D32`
- Communication: `#F57C00`
- Scientific / sensor layer: `#C62828`
- Desktop software: `#7B1FA2`
- User / external context: `#616161`

## Drawing rules
- White background.
- Flat 2D technical diagrams only.
- No gradients, shadows or decorative 3D effects.
- Rounded rectangles with 2 pt equivalent borders.
- Sans-serif typeface (Liberation Sans / Arial compatible).
- One engineering question per figure.
- Keep implementation-specific pin names out of System Views unless the pin itself is the architectural subject.
- Source format: SVG or draw.io; PDF is the LaTeX publication format.
